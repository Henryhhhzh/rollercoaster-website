# The Long Drop

Website for our Year 9 STEM marble roller coaster, by Henry & Michael.

Open `index.html` in a browser to view it.

## Media files

Put these in a `media/` folder, using these exact names:

| File | What it shows |
|------|---------------|
| `logo.svg` | Coaster logo, exported from VectorPea |
| `hero.jpg` | Best photo of the finished coaster |
| `test-run.mp4` | Test run video (keep it under 50 MB) |
| `chosen-design.jpg` | Chosen group design, with notes |
| `sketch-henry.jpg` | Henry's concept sketch |
| `sketch-michael.jpg` | Michael's concept sketch |
| `model-front.jpg` | Front view |
| `model-side.jpg` | Side view |
| `model-top.jpg` | Top-down view |
| `model-start.jpg` | Close-up of the start and runway |
| `model-loop.jpg` | Close-up of the loop |
| `model-supports.jpg` | Close-up of the straw supports |
